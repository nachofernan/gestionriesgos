FASE 2: LÓGICA DE NEGOCIO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Estado: ✓ COMPLETADO 100%

Qué se logró:
  ✓ Cálculo automático de riesgo: Sistema que calcula criticidad
    basado en impacto y probabilidad (escala 0-10)

  ✓ Lógica de control: Mitigación de riesgos mediante controles
    (cada control reduce el valor residual del riesgo)

  ✓ Asociaciones múltiples: Un riesgo puede tener múltiples controles,
    objetivos y planes de acción

  ✓ Recálculo de criticidad: El sistema recalcula automáticamente
    valores de riesgo residual cuando cambian controles


FASE 3: GESTIÓN DE PLANES Y TAREAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Estado: ✓ COMPLETADO 100%

Qué se logró:
  ✓ Evolución de planes: Cada plan de acción tiene código único (PA-0001,
    PA-0002, etc.) y estado (borrador, validado, activo)

  ✓ Avance de tareas: Cada tarea registra porcentaje de avance (0-100%)
    y fecha de cumplimiento

  ✓ Historial auditable: Sistema automático que registra TODOS los cambios
    realizados en planes, tareas y riesgos (quién cambió qué y cuándo)

  ✓ Documentación adjunta: Capacidad de cargar archivos y documentación
    en cada elemento

  ✓ Indicadores de progreso: Vista de progreso porcentual por plan
    y estado consolidado de tareas


FASE 4: ASOCIACIÓN DE USUARIOS, ÁREAS Y GERENCIAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Estado: ✓ COMPLETADO 100%

Qué se logró:
  ✓ Estructura organizacional: Modelo jerárquico de áreas que refleja
    la estructura real de la empresa (gerencias y sectores)

  ✓ Sectorización: Cada riesgo, control y plan está asociado a un área
    específica

  ✓ Administración de accesos: Sistema de permisos basado en jerarquía:
    - Gerentes: ven y modifican su área y sub-áreas
    - Comité: acceso total a cualquier área
    - Empleados: solo ven elementos de su sector

  ✓ Validación de autorización: El sistema impide que un gerente vea
    o modifique elementos de otras gerencias

  ✓ Usuarios asociados: Cada elemento es responsabilidad de un usuario
    específico dentro de su área
