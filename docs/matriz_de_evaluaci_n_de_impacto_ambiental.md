# Matriz de Evaluación de Aspectos e Impactos Ambientales

## 1. Caracterización (La valoración no es numérica)

### Temporalidad

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Pasado** | **P** | Actividades, productos, servicios remanentes de una actividad pasada que no continúa en la actualidad. |
| **Actual** | **A** | Actividades, productos, servicios que se llevan a cabo en el presente. |
| **Futuro** | **F** | Actividades, productos, servicios planificados (ej. nuevos equipos, ampliaciones, nuevos proyectos, etc.). |

### Condición

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Normal** | **N** | Actividades, productos, servicios que se llevan a cabo en condiciones operativas normales. |
| **Contingencia** | **C** | Incidentes, accidentes y situaciones de emergencia. |

### Responsabilidad

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Directa** | **D** | Cuando el aspecto ambiental está vinculado directamente a las actividades, productos y servicios de la empresa, y que por lo tanto pueden ser controlados. Incluye la actividad de contratistas y proveedores dentro del predio de la empresa. |
| **Indirecta** | **I** | Cuando el aspecto ambiental deriva de las actividades, productos y servicios de la empresa, pero sobre los cuales no puede ejercerse control directo, aunque puede ejercerse cierta influencia sobre los mismos (ej. disposición final de residuos especiales, transporte realizado por terceros, etc.). |

## 2. Probabilidad: Control + Frecuencia

### Control

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Aspecto no controlado** | **5** | • No tiene procedimientos escritos<br>• No se realizan mediciones<br>• No tiene sistema de protección o barreras |
| **Aspecto parcialmente controlado** | **3** | • Cuando los procedimientos escritos o instrucciones no son suficientes para el control<br>• Cuando las mediciones realizadas no son periódicas<br>• Cuando las barreras o sistemas de protección no son suficientes |
| **Aspecto controlado** | **1** | • Cuando tienen implementadas medidas de control operativo<br>• Cuando se realizan mediciones periódicas<br>• Cuando son efectivas las barreras físicas |

### Frecuencia

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Muy frecuente** | **5** | • Cuando se produce o puede producirse con una frecuencia diaria |
| **Frecuente** | **3** | • Cuando se produce o puede producirse con una frecuencia semanal o mensual |
| **Poco Frecuente** | **1** | • Cuando se produce o puede producirse en forma no periódica |

## 3. Consecuencia (o Impacto)

**Fórmula:** $Medio\ sobre\ el\ que\ ocurre\ el\ impacto + Naturaleza\ del\ elemento\ contaminante + Magnitud\ de\ Impacto$

### Medio sobre el que ocurre el impacto

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Muy sensible** | **3** | Cercanías a centros poblados, napas subterráneas poco profundas. |
| **Sensible** | **2** | Suelo, áreas pobladas. |
| **Poco sensible** | **1** | Zona industrial, pisos con cemento. |

### Naturaleza del elemento contaminante

| Criterio | Val | Descripción |
| ----- | ----- | ----- |
| **Peligrosa** | **3** | Sustancias corrosivas, inflamables, reactivas, carcinogénicas, tóxicas, irritantes, lixiviables, mutagénicas, teratogénicas e infecciosas, y aquellas mencionadas en la ley 11720 de la provincia de Buenos Aires. |
| **Poco Peligrosa** | **2** | Ruidos, vibraciones, residuos domiciliarios. |
| **No Peligrosa** | **1** | El elemento no es contaminante. |

### Magnitud del Impacto ($I + Ex + Mo + Rv + Ef + Mc$)

| Variable | Descripción |
| ----- | ----- |
| **Intensidad ($I$)** | Intensidad o grado probable de destrucción. Se refiere al grado de incidencia de la acción sobre el factor. Puede ser baja (afección mínima) o total (destrucción total). |
| **Extensión ($Ex$)** | Área de influencia del impacto con relación al entorno. |
| **Momento ($Mo$)** | Es el plazo en que se manifiesta el impacto. Es el tiempo que transcurre entre la aparición de la acción y el comienzo del efecto (largo plazo, medio plazo o inmediato). |
| **Reversibilidad ($Rv$)** | Se refiere a la reconstrucción, es decir, la posibilidad de retornar a las condiciones iniciales previas a la acción, **POR MEDIOS NATURALES**. |
| **Efecto ($Ef$)** | Es la relación causa-efecto. |
| **Recuperabilidad ($Mc$)** | Se refiere a la posibilidad de reconstrucción, total o parcial, del factor afectado. Es decir, la posibilidad de retornar a las condiciones iniciales previas a la acción, **POR MEDIO DE LA INTERVENCIÓN HUMANA**. |

*Nota: La sumatoria total de la Magnitud del Impacto es del 1 al 4 según la tabla de Clasificación.*

## 4. Clasificación del Significado

| Clasificación | Val | Descripción |
| ----- | ----- | ----- |
| **BAJO** | **1** | La afección de este es irrelevante. |
| **MODERADO** | **2** | La afección de este no precisa prácticas correctivas. |
| **SEVERO** | **3** | La afección de este exige la recuperación de las condiciones del medio a través de medidas correctivas. |
| **CRÍTICO** | **4** | La afección de este produce una pérdida permanente de la calidad en las condiciones ambientales. No existe posibilidad de recuperación. |
